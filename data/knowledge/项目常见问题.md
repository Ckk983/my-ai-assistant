# 项目常见问题

## 密钥怎么配置？
密钥写在项目根目录的 .env 文件里，变量名叫 LLM_API_KEY。
.env 不会被上传到 GitHub，仓库里只有模板文件 .env.example。
如果 .env 里的密钥还是占位符，程序会返回明确的提示，而不是报一堆看不懂的异常。

## 服务默认跑在哪个端口？
默认端口是 8000。启动命令是 uvicorn app.main:app --reload --port 8000。
启动后访问 http://127.0.0.1:8000/docs 可以看到自动生成的接口文档。

## 怎么跑测试？
在项目根目录执行 pytest 即可。合计 14 个测试用例，覆盖了存储层的存读、历史截断、
空会话兜底和会话之间数据不串这四种情况。
每次 push 后 GitHub Actions 也会自动在干净环境里跑一遍同样的测试。

## 数据存在哪里？
对话记录存在 data/history.json，按 session_id 分组保存，每条包含 role、content 和时间。
密钥存在 .env 这个本地文件里。程序日志放在 logs 目录。

## 为什么不能把密钥写进代码？
因为代码要上传到 GitHub。密钥写进代码等于公开，会被爬虫扫到并盗刷。
正确做法是放 .env 并写进 .gitignore。
