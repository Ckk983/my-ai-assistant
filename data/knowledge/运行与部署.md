# 运行与部署

## 本地怎么启动项目？
第一步创建虚拟环境；第二步装依赖；第三步启动服务。
启动命令是 uvicorn app.main:app --reload --port 8000。
注意服务是常驻进程，启动后那个窗口要一直开着，测试脚本要另开一个窗口跑。

## 为什么不用 activate 命令？
因为 PowerShell 的执行策略可能禁止运行激活脚本。直接用解释器的全路径来执行
更省事，效果完全一样。

## 有哪些一键验证的脚本？
scripts 目录下有测试脚本，会自动做两轮对话：先告诉它一个信息，再问它是否记得，
用来验证服务能否正常应答，以及多轮记忆是否生效。

## 持续集成是怎么配的？
用 GitHub Actions，配置文件在 .github/workflows/ci.yml。
每次推送到 main 分支，GitHub 会自动开一台干净的 Ubuntu 机器，
装 Python 和依赖，然后跑 pytest，单次流水线大约 15 秒。
测试失败会发邮件通知。

## 项目有哪些接口？
GET / 是健康检查，能看到服务是否存活以及密钥是否配好。
POST /chat 是核心接口，用来提问和获取回答。
GET /history/{session_id} 查某个会话的历史记录。
GET /sessions 列出所有会话的 ID。
